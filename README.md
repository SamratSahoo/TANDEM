# TANDEM

**TANDEM** (Task and Motion Planning with As-Needed Demonstrations) is a system that combines task and motion
planning with selective human teleoperation to collect demonstrations for tasks beyond a planner's capabilities.

**[Documentation](https://prpl-group.com/tandem/docs/)** · [Paper website](https://prpl-group.com/tandem/)

The documentation covers:

- [Installation](https://prpl-group.com/tandem/docs/installation/): what you need, and `tandem init` on the
  robot workstation
- [Robot setup](https://prpl-group.com/tandem/docs/robot/), [perception servers](https://prpl-group.com/tandem/docs/perception-servers/),
  [cameras and calibration](https://prpl-group.com/tandem/docs/cameras/) and
  [teleoperation](https://prpl-group.com/tandem/docs/teleop/)
- [Your first collection](https://prpl-group.com/tandem/docs/getting-started/), then
  [collecting](https://prpl-group.com/tandem/docs/collecting/) and
  [reviewing and exporting](https://prpl-group.com/tandem/docs/reviewing/)
- [Configuration](https://prpl-group.com/tandem/docs/configuration/), the
  [command reference](https://prpl-group.com/tandem/docs/commands/), the
  [data format](https://prpl-group.com/tandem/docs/data/) and
  [troubleshooting](https://prpl-group.com/tandem/docs/troubleshooting/)
- [Adding a planner](https://prpl-group.com/tandem/docs/adding-a-planner/) and
  [adding a human executor](https://prpl-group.com/tandem/docs/adding-a-human-executor/)
